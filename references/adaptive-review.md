# 章末复盘与自适应复习

复习池由 `kaoyan.config.json` 的 `review_subjects` 决定，默认 `["数学", "408"]`，保持原有范围。加入英语或政治后，使用相同的复盘记录、间隔、到期队列与完成统计；不在列表中的科目不进入池。配置复习科目本身不改变正式进度或学习记录的授权规则。章内以自然追问和必要即时变式确认理解，不另设固定微复习。

## 触发与记录

用户明确确认教材大章节结束才启动正式章末复盘，不根据视频或页码推断。复盘含章节骨架、基础代表题、真实薄弱题及一题近邻变式/辨析；多知识点分别评价。教材题继续按 [教材问答](textbook-qa.md) 核验。

客观结果为 `right`、`partial`、`wrong`，熟练度及默认间隔见下表（均可配置）；两者独立，调度取较弱信号，不用整题总评遮盖局部卡点。

| 熟练度 | 首次间隔 | 后续间隔 |
| --- | --- | --- |
| `very_fluent` 非常熟练 | 14 天 | 当前 × 2，最多 45 天 |
| `fairly_fluent` 比较熟练 | 7 天 | 当前 × 1.5，最多 21 天 |
| `not_fluent` 不太熟练 | 3 天 | 重置 3 天 |
| `needs_remediation` 需要回补 | 1 天 | 重置 1 天 |

用户完成正式复盘并给出各知识点结果与熟练度，即授权 learner 写入。用 `learner exercise --batch-json <file>` 预览整批，全部验证通过后追加 `--yes` 原子写入，不等日终收束。保留原始时间、来源任务/消息 ID、稳定知识点键、客观结果、主观熟练度、提示使用情况及派生到期日。普通讲题、零散自评、未完成复盘继续零写入。

## 到期复习

已配置科目的学习会话开始时可用 `learner review-followups --plan-date YYYY-MM-DD` 查询。每天默认最多 20 分钟、3 个知识点、一道完整数学计算题；超量按需要回补、不太熟练、比较熟练、非常熟练及逾期时长滚动，不要求清零。需要回补先定点解释并做基础近邻题，不要求重学整章。

只有章末复盘、计划复习、反复确认的真实卡点或用户指定重点进入池。真实提取/做题并评级才算完成；查询队列、打开会话或无到期项不产生完成记录。

## 配置与优先级

`review_subjects` 是非空、不重复的规范名称数组，可选 `数学`、`408`、`英语`、`政治`、`洛谷`、`算法竞赛`。这采用已知科目名校验，不接受任意字符串、别名、空名称或未知名称；配置错误会明确报错，绝不退回默认科目或静默产生空池。数学、英语、408、政治对应 learner 的现有学科名称；另保留两个历史练习分类，使原先的排除范围也可显式启用。

事件仍沿用旧标签的大小写不敏感子串识别：数学匹配“数学”；408 匹配“408 / 数据结构 / 计算机组成 / 操作系统 / 计算机网络”；英语匹配“英语 / english”，其余匹配同名文本。为兼容旧的混合标签，含英语、洛谷、算法竞赛时依此次序优先归入对应类别，再由配置决定是否启用；否则数学/408 等匹配项任一启用即可。配置使用规范名称，例如启用 `英语` 也会接收历史 `English` 标签。

`adaptive_review` 可省略，内部字段及每个熟练度的子字段也可分别省略；缺省部分沿用下表。优先级为**显式 CLI 参数 > 配置值 > 内置默认值**；现有 `--time-budget-minutes`、`--max-items` 覆盖同名配置，未传参数时不会覆盖配置。其他字段通过配置设置。

| `adaptive_review` 字段 | 默认值 | 含义 |
| --- | --- | --- |
| `intervals` | 下表 | 各熟练度间隔规则 |
| `time_budget_minutes` | 20 | 当日队列耗时上限（分钟） |
| `max_items` | 3 | 当日最多知识点数 |
| `max_full_math_items` | 1 | 当日最多完整数学计算题（数学标签且带 `full_calculation`） |
| `math_default_minutes` | 10 | 数学未提供正耗时时的估计 |
| `default_minutes` | 5 | 其他科目未提供正耗时时的估计；旧事件缺耗时的队列估计 |
| `min_estimated_minutes` / `max_estimated_minutes` | 3 / 12 | 新记录耗时估计的裁剪范围 |
| `min_interval_days` | 1 | 非重置的后续间隔下限 |

| `intervals` 熟练度 | `initial_days` | `multiplier` | `max_days` |
| --- | --- | --- | --- |
| `very_fluent` | 14 | 2 | 45 |
| `fairly_fluent` | 7 | 1.5 | 21 |
| `not_fluent` | 3 | 0 | 3 |
| `needs_remediation` | 1 | 0 | 1 |

首次或无正历史间隔时使用 `initial_days`；`multiplier=0` 表示每次重置为 `initial_days`，此时不使用 `max_days`。否则后续间隔为 `min(max_days, max(min_interval_days, round(上次间隔 × multiplier)))`，取整沿用 Python `round`。客观结果对有效熟练度的限制、薄弱项及逾期优先排序保持原规则。

所有数值必须非负且有限；只有 `multiplier` 可为小数，其他字段必须为整数，布尔值和数字字符串均不接受。耗时下限不能大于上限，使用倍率的间隔上限不能小于 `min_interval_days`；未知字段或熟练度也报错。数量或预算为 0 会显式禁选并返回 `deferred_by_budget`（有到期项时）；`initial_days=0` 可表示当天到期。

例如在原配置中加入以下字段即可启用英语，并调整首次间隔及每日上限；其他规则继续用默认值：

```json
{
  "review_subjects": ["数学", "408", "英语"],
  "adaptive_review": {
    "intervals": {
      "very_fluent": {"initial_days": 10, "multiplier": 2, "max_days": 40}
    },
    "time_budget_minutes": 25,
    "max_items": 4
  }
}
```

此时 `learner review-followups --plan-date YYYY-MM-DD` 使用 25 分钟/4 项；显式传 `--max-items 2` 则仅覆盖为 2 项。移除科目会立即从到期队列与完成统计排除其记录；重新加入可恢复读取历史。调整间隔和耗时估计只作用于后续新记录，不重写已有事件的到期日或估计值；`review_schedule.json` 仍是重建时生成的派生视图，查询队列以事件和当前配置为准。
